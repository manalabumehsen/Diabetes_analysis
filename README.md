# Diabetes_analysis
EDA for Diabetes datasets
## Goal
Exploratory Data Analysis (EDA) on the Diabetes dataset to understand the distribution of numerical and categorical columns and identify outliers.

## Project Content
- diabetes_analysis.ipynb : Notebook with analysis code and visualizations.
- Dataset: small sample or link to the original Kaggle dataset.

## Steps
1. Data cleaning (duplicates and missing values).
2. Descriptive analysis of numerical and categorical columns.
3. Visual analysis:  
   - Histograms for numerical columns  
   - Countplots for categorical columns  
   - Boxplots to detect outliers  
   - Heatmap for correlations between numerical columns
4. Quick insights on the relationship between features and the target Diabetes_012.

## Notes
- Dataset source: [Diabetes Health Indicators Dataset on Kaggle](https://www.kaggle.com/datasets).
